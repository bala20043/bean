# Brew & Bean Delight

Create a polished, modern and visually attractive frontend-only café website for a fictional café called “Brew & Bean.”

The website should feel like a premium, welcoming modern coffee shop website and should be fully responsive on desktop, tablet and mobile.

Brand

Name: Brew & Bean

Create a simple elegant café logo using the Brew & Bean name with a subtle coffee-bean/coffee-cup concept.

Main Navigation

Create a sticky navigation bar containing:

Home

Menu

About Us

Offers

Gallery

Contact

Add prominent CTA buttons:

Order Now

Reserve a Table

Use smooth scrolling between sections.

Homepage / Hero

Create a visually impressive hero section with a high-quality café/coffee background or hero image.

Headline:
“Good Coffee. Great Moments.”

Subheading:
“Handcrafted coffee, delicious bites, and a warm place to slow down.”

Buttons:

Explore Menu

Reserve a Table

Add a small visual indicator such as “Freshly brewed daily.”

Signature Drinks

Create a featured section titled:

“Our Signature Brews”

Show attractive cards for:

Caramel Macchiato

Classic Cappuccino

Spanish Latte

Mocha Bliss

Each card should contain:

Image

Name

Short description

Price

Order button

Add subtle hover animations.

Menu Section

Create a complete menu section with category filter buttons:

All

Coffee

Tea

Snacks

Desserts

Display menu items as attractive cards.

Each menu card should contain:

Food/drink image

Item name

Short description

Price

Order button

The category filters must work using frontend interactions. Selecting a category should dynamically display only the relevant menu items.

Use realistic fictional prices in Indian Rupees (₹).

Special Offers

Create an attractive promotional section titled:

“Brew More, Save More”

Include cards such as:

Morning Brew Combo
Coffee + Croissant

Student Special
10% OFF with student ID

Weekend Treat
Coffee + Dessert combo

Add a “Claim Offer” button that displays a simple frontend confirmation message.

About Us

Create a warm storytelling section explaining the fictional Brew & Bean café.

Include:

Café story

Freshly roasted beans

Freshly prepared food

Comfortable ambience

Add an attractive café image.

Ambience Section

Create a section showcasing the café atmosphere.

Highlight:

Cozy seating

Warm lighting

Free Wi-Fi

Workspace-friendly environment

Relaxing music

Gallery

Create a responsive image gallery featuring:

Coffee

Café interior

Desserts

Barista preparing coffee

Cozy seating

Café exterior

Use a modern masonry/grid layout.

Clicking an image should open a simple frontend lightbox/modal.

Order Now

Create a frontend-only order interface.

When the user clicks “Order Now,” open a modal or side panel containing:

Selected item

Quantity selector

Price

Add to order button

Order summary

Do NOT implement real payment processing or a backend.

After placing an order, display:
“Your order has been received! Thank you for choosing Brew & Bean.”

Reserve a Table

Create a frontend-only reservation modal/form containing:

Name

Email

Phone

Date

Time

Number of guests

Add a “Confirm Reservation” button.

After submission, display a confirmation message:
“Your table reservation request has been received!”

No backend is required.

Contact

Create a contact section containing:

Café address

Phone number

Email

Opening hours

Contact form

Use fictional café contact information.

Add a map-style visual/location card without requiring a real map API.

Footer

Create a professional footer containing:

Brew & Bean logo

Short café description

Navigation links

Opening hours

Contact information

Social media icons

Copyright

Visual Design

Use a sophisticated café-inspired visual language.

Requirements:

Premium modern UI

Warm and inviting atmosphere

Elegant typography

High-quality food and coffee imagery

Rounded cards

Soft shadows

Subtle animations

Smooth hover effects

Clean spacing

Strong visual hierarchy

Responsive layout

Mobile-friendly navigation

Avoid making the website look like a generic template.

Technical Requirements

This is a frontend-only prototype.

Use:

React

Modern CSS/Tailwind styling

Component-based architecture

Local/static data for menu items

Frontend state for menu filtering

Frontend modals for ordering and reservation

Do not require authentication, database, payment gateway, or backend.

Make every button and interaction functional within the frontend.

Before finishing, verify:

Menu category filters work.

Order Now opens the order interface.

Reserve a Table opens the reservation form.

Forms show confirmation messages.

Gallery lightbox works.

Navigation works.

Website is responsive.

No broken images or buttons.

The final result looks polished enough for a hackathon/demo presentation.
